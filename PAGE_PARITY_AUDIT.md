# English–Hisabati Page Parity Audit

Each English page is reviewed using three sources:

1. The corresponding page in `MATHEMATICS STD III PB (SEPT 2025).pdf` for English text, order, diagrams, and exact page composition.
2. The published Hisabati reader at `http://reelma.me/hisabati-kitabu-cha-mwanafunzi-darasa-la-3/` for the shared visual language and component implementation.
3. The English HTML at `http://127.0.0.1:4175/` for the rendered result.

The editions do not always place the same component on the same numbered page. When pagination differs, use the Hisabati page containing the same topic/component rather than copying the same filename blindly.

## Required checks per page

- preserve the existing English wording verbatim; layout work must never rewrite, simplify, expand, or remove words
- fixed page shell, top/bottom gradients, and page-number tab
- content-column start/end alignment
- body, heading, label, number, and table typography
- vertical spacing and safe gradient clearance
- Example, Exercise, Activity, Reminder, Vocabulary, and chapter components
- table geometry, colors, borders, and header emphasis
- arithmetic notation and double answer lines
- diagram source, crop, transparency, scale, orientation, and alignment
- absence of screenshots where semantic HTML is required
- absence of nested or duplicated decorative wrappers

## Global typography and completeness correction (parity v254)

- ordinary prose, questions, labels, table text and inline content use a shared 20px body size with 1.3 line-height
- ordinary content sections use a shared 710px source column; chapter/component titles retain their larger hierarchy
- calendar grids retain their intentionally compact 12px type
- page-local extraction rules may not reduce or enlarge ordinary body text
- source details must not be hidden to satisfy a preset panel height; confirmed clipped sections on printed pages 45, 59, 62 and 163 were released and re-fitted
- full-book automated inspection covers body-size frequency, section width and clipped-overflow detection; representative early, middle and late pages were re-rendered against the PDF
