Reading and writing whole numbers exceeding 10000

In order to easily read or write whole numbers exceeding 10000, identify the place value of each digit of a given whole number.

Example 1

Write the place value of each digit in 61270, then write the number in words.

Answer

The place values of the digits in 61270 are as follows:

0 is in ones
7 is in tens
2 is in hundreds
1 is in thousands
6 is in ten thousands

Therefore, 61270 is read as sixty-one thousand two hundred and seventy.

Example 2

Write the place value of each digit in 876543, then write the number in words.

Answer
3 is in ones
4 is in tens
5 is in hundreds
6 is in thousands
7 is in ten thousands
8 is in hundred thousands

Therefore, 876543 is read as eight hundred seventy-six thousand five hundred and forty-three.
