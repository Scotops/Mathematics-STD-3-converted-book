Total value of a digit in a whole number

The total value of a digit in a number increases from right to left. It is obtained by considering the place value of a digit.

Example 1

Write the total value of each digit in 9672.

Answer

Example 2

Write the total value of each underlined digit in 8794.

Answer

The total value of 9 is 90

The total value of 8 is 8000

Example 3

Given the number 7985, write the following:

(a) The place value of each digit

(b) The total value of each digit

Answer

Number Digit (a) Place value (b) Total value
7985 7 Thousands 7000
9 Hundreds 900
8 Tens 80
5 Ones 5
